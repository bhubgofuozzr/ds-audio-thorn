## Overview

Thorn is a wavetable synthesizer designed for aggressive sound design, featuring custom wavetable import, an analog-modeled ladder filter, multiband distortion, and a high-density unison engine.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **DS Audio Thorn** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Wavetable Import** | Load custom single-cycle waveforms from WAV files into oscillators |
| **Ladder Filter** | Analog-modeled 4-pole Moog-style ladder with drive and resonance |
| **Multiband Distortion** | Independent saturation stages per frequency band in the FX chain |
| **Unison Stack** | Up to 15 voices per oscillator with configurable spread and phase |
